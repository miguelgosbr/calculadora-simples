# 🧮 Calculadora Simples em TypeScript

Este é um projeto simples de calculadora desenvolvido em TypeScript para praticar conceitos básicos da linguagem, como declaração de variáveis, funções com parâmetros e retornos, e exibição de dados no console.

## 🚀 Funcionalidades

A calculadora possui funções para as quatro operações matemáticas básicas:
- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

## 🛠️ Pré-requisitos

Antes de começar, você precisará ter instalado em sua máquina:
* [Node.js](https://nodejs.org/) (Versão LTS recomendada)
* [TypeScript globalmente](https://www.typescriptlang.org/) (necessário para compilar o código)
* [Git](https://git-scm.com/)

Para instalar o TypeScript de forma global no seu computador, execute o comando abaixo no seu terminal (necessário apenas uma vez):
```bash
npm install -g typescript
```

## 🔧 Como executar o projeto

Siga os passos abaixo para rodar o projeto localmente de forma simples e leve, sem necessidade de pasta `node_modules`:

### 1. Clonar o repositório
```bash
git clone https://github.com/SEU_USUARIO/calculadora-simples.git
```

> *Nota: Substitua `SEU_USUARIO` pelo seu nome de usuário no GitHub.*

### 2. Entrar na pasta do projeto
```bash
cd calculadora-simples
```

### 3. Compilar o TypeScript para JavaScript
Converta o arquivo `.ts` para `.js`:
```bash
tsc calc.ts
```
*(Isso criará automaticamente o arquivo `calc.js` na sua pasta)*

### 4. Executar o código
Execute o arquivo JavaScript gerado usando o Node.js:
```bash
node calc.js
```
